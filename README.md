# Social Studies Activities

Classroom websites for U.S. History, World History, Sociology, and Government.

- **Home page:** https://neotboy.github.io/socialstudies1800/ (activities sorted by class)
- **Teacher dashboard:** https://neotboy.github.io/socialstudies1800/teacher-submissions/ (one code, a tab per class)

## Where student work goes
Every activity that turns in work uses `shared/turnin.js`. The address of the Google Sheet saver is at the top of that file.
To add a new activity to the dashboard, add one line to `shared/assignments.js`.

## Day 4: Major Sociological Theories

The Sociology Casebook is a 20–25 minute team activity applying functionalism, conflict theory, and symbolic interactionism to three real cases.

- [Open the Day 4 activity](https://neotboy.github.io/socialstudies1800/day-4-theory-casebook/)
- [Teacher answer dashboard](https://sociology-theory-showdown.neotboy.chatgpt.site/teacher.html)

The Google Sheet saver itself is `shared/google-saver/Code.gs`. Setup steps are at the top of that file. The teacher code is stored in the script's settings, never in this public site.
